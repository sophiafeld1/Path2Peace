Path to Peace (aka Path2Peace) website

this web site is a therapists website using next.js
it deploys to vercel

# Goals
Quickly revise, extend, review look and feel
Add offerings, workships, and other specific content easily
Add blogs (via direct next.js or related content, not a CMS)

# Themes
Warm, friendly, modern
Some kid-friendly indications, but a warm modern feel overall

Nature photos are used, including paths through the woods to a destianion
Trees
Some rocks/water

Colors should work with natural imagery

Brand palette (tokens, hex values, role assignments, and the temperature-
matching rule for decorative accents) lives in ./colors.txt — consult and
update that file when reasoning about color.

# SEO
Specific modalities and offerings should be present
EMDR, IFS, somatic and other therapies offered
Blogs and periodic updates on consistent themes help

# Position
Experienced therapists (vs bulk/corporate services with lower skilled therapists)
Relationship oriented
Trusted
Local and often in-person in or around Reston, VA
